## Purpose

We aim to capture the volume of engagement around different topics across the internet. We use public and private APIs to obtain data.

To most accurately measure attention, we prioritize active engagement over passive engagement and apply source-level weighting to down-weight signals susceptible to artificial inflation.

The methodology for our **general attention index** is shown below.

<Warning>
  The specific methodologies may vary depending on the market category. Be sure to check the methodology of each index **before** placing a trade.
</Warning>

## Data Collection

Raw metrics are aggregated at fixed intervals using keyword-based querying, log-transformed, and combined using pre-defined weights.

The keyword we use is the same as the name of the respective market.

<Tip>
  For example, the “Claude Code” market uses “Claude Code” as its keyword.
</Tip>

Most engagement data follows a power law. So, we apply a $log(x+1)$ transformation on each metric to stabilize variance and mitigate the impact of outliers.

## Sources

We integrate data from four primary platforms. All metrics are collected at fixed intervals and normalized to a **15-minute baseline** to ensure consistency across different polling frequencies.

<Tabs>
  <Tab title="YouTube">
    ### **YouTube Data API v3**

    - **Frequency:** Hourly (Normalized to 15 minutes: Value / 4).
    - **Discovery:** We use the `search.list` endpoint (`type.video`, `order.relevance`, `publishedAfter: t-24h`) to identify the 50 most relevant videos.
    - **Metrics:** We pull `viewCount`, `likeCount`, and `commentCount` via the `videos.list` endpoint.

    | Metric         | Weight |
    | :------------- | :----- |
    | `totalResults` | 0.50   |
    | `commentCount` | 0.30   |
    | `likeCount`    | 0.15   |
    | `viewCount`    | 0.05   |

    We apply a $log(x+1)$ transformation to each metric before summing for the final platform contribution.
  </Tab>
  <Tab title="Reddit">
    ### **Reddit Public API**

    - **Frequency:** Hourly (Normalized: Value / 4).
    - **Discovery:** We use the `search` endpoint (`t=day`, `sort=top`) to obtain the top 100 posts.
    - **Metrics:** We paginate through results to count total posts, `ups` (upvotes), and `num_comments`.

    | Metric         | Weight |
    | :------------- | :----- |
    | `Total Posts`  | 0.50   |
    | `num_comments` | 0.30   |
    | `ups`          | 0.20   |
  </Tab>
  <Tab title="X (Twitter)">
    ### **TwitterAPI.io (Paid)**

    - **Frequency:** Every 30 minutes (Normalized: Value / 2).
    - **Discovery:** We use the `advanced_search` endpoint (`queryType="top"`) looking at the last hour of activity.
    - **Metrics:** We paginate up to 100 posts, summing `likeCount`, `replyCount`, and `retweetCount`.

    | Metric         | Weight |
    | :------------- | :----- |
    | `Total Posts`  | 0.50   |
    | `replyCount`   | 0.30   |
    | `retweetCount` | 0.15   |
    | `likeCount`    | 0.05   |
  </Tab>
  <Tab title="Google Trends">
    ### **SerpAPI Google Trends SDK**

    - **Frequency:** Hourly (Not normalized).
    - **Standardization:** To eliminate volatility, we calibrate results against four stable control terms: _ankle sprain, wrist pain, broken bone,_ and _blurry vision_.

    1. **Calculate Baseline:** We take the simple average of the four control terms.
    2. **Standardize Keyword:** We divide the keyword's average interest by the (baseline average + 1).
    3. **Final Metric:** We apply a <Latex>
         \\log(x+1)
       </Latex>
        transformation to the result.

    <Expandable title="Example: Claude Code">
      If **"Claude Code"** has an interest of `35.0` and the control baseline is `1.0`: $\log(35.0 / (1.0 + 1)) = \log(17.5)$
    </Expandable>
  </Tab>
</Tabs>

## Final Calculation

The **Attention Index** is the final weighted combination of the Social Basket and Google Trends, scaled by a factor of 10.

### The Master Formula

$Index = 10 \cdot [0.30G + 0.70(0.40Y + 0.30R + 0.30X)]$

| Variable | Platform      | Weight              |
| :------- | :------------ | :------------------ |
| **G**    | Google Trends | 30%                 |
| **Y**    | YouTube       | 28% (40% of Social) |
| **R**    | Reddit        | 21% (30% of Social) |
| **X**    | X (Twitter)   | 21% (30% of Social) |

<Expandable title="Step-by-Step Example Walkthrough">
  Suppose platform scores (post-transformation) are **Y: 6.0, R: 4.0, X: 5.0, G: 1.0**:

  1. **Social Metric:** $0.40(6.0) + 0.30(4.0) + 0.30(5.0) = 5.10$
  2. **Preliminary Index:** $0.30(1.0) + 0.70(5.10) = 3.87$
  3. **Final Index:** $3.87 \cdot 10 = \mathbf{38.7}$ (Index Points)
</Expandable>
