## Purpose

We aim to capture the volume of engagement around different topics across the internet. We use public and private APIs to obtain data.

To most accurately measure attention, we prioritize active engagement over passive engagement and apply source-level weighting to down-weight signals susceptible to artificial inflation.

The methodology for our **general attention index** is shown below.

<Warning>
  The specific methodologies may vary depending on the market category. Be sure to check the methodology of each index **before** placing a trade.
</Warning>

## Data Collection

Raw metrics are aggregated at fixed intervals using keyword-based querying, log-transformed, and combined using pre-defined weights.

The keyword we use is the same as the name of the respective market.

<Tip>
  For example, the “Claude Code” market uses “Claude Code” as its keyword.
</Tip>

Most engagement data follows a power law. So, we apply a $log(x+1)$ transformation on each metric to stabilize variance and mitigate the impact of outliers.

## Sources

We integrate data in our general index from four primary platforms. All metrics are collected at fixed intervals and normalized to a 15-minute baseline to ensure consistency across different polling frequencies.

<Tabs>
  <Tab title="YouTube">
    ### **YouTube Data API v3 (Public)**

    - **Frequency:** Data collected hourly, normalized to 15 minutes (metrics divided by 4 pre-transformation).
    - **Discovery:** We use the `search.list` endpoint (`type.video`, `order.relevance`, `publishedAfter: t-24h`, `q={keyword}`) to obtain a list of the video IDs of the 50 most relevant videos published over the last 24 hours. This call also returns `totalResults`, which we use in our calculations below.
    - **Metrics:** We use the `videos.list` endpoint (`part.statistic`, `id={50 video IDs}`) to find `viewCount`, `likeCount`, and `commentCount`. We convert these integer returns into strings.

    We apply a $log(x+1)$ transformation to each metric and then apply the following weights:

    | Metric         | Weight |
    | :------------- | :----- |
    | `totalResults` | 0.50   |
    | `commentCount` | 0.30   |
    | `likeCount`    | 0.15   |
    | `viewCount`    | 0.05   |

    We sum these metrics to score YouTube's contribution to the index.
  </Tab>
  <Tab title="Reddit">
    ### **Reddit API (Public)**

    - **Frequency:** Data collected hourly, normalized to 15 minutes (metrics divided by 4 pre-transformation).
    - **Discovery:** We use the `search` endpoint (`t=day`, `sort=top` ,`limit=100`, `q={keyword}`),  to obtain a paginated list of the top 100 posts.
    - **Metrics:** We paginate through results to count the total number of posts over the last 24 hours (`Total Posts`). For each post, we also count`ups` (upvotes), and `num_comments`. We sum total `ups` and total `num_comments` across all posts.

    We apply a $log(x+1)$ transformation to each metric and then apply the following weights:

    | Metric         | Weight |
    | :------------- | :----- |
    | `Total Posts`  | 0.50   |
    | `num_comments` | 0.30   |
    | `ups`          | 0.20   |

    We sum these metrics to score Reddit's contribution to the index.
  </Tab>
  <Tab title="X (Twitter)">
    ### **TwitterAPI.io API (Paid)**

    - **Frequency:** Data collected every 30 minutes, normalized to 15 minutes (metrics divided by 2 pre-transformation).
    - **Discovery:** We use the `advanced_search` endpoint `query={keyword, time frame}`,`queryType="top"`), looking at posts over the last hour. This returns a paginated list with 20 results per page.
    - **Metrics:** We paginate up to 100 posts, summing `likeCount`, `replyCount`, and `retweetCount`across all posts.

    We apply a $log(x+1)$ transformation to each metric and then apply the following weights:

    | Metric         | Weight |
    | :------------- | :----- |
    | `Total Posts`  | 0.50   |
    | `replyCount`   | 0.30   |
    | `retweetCount` | 0.15   |
    | `likeCount`    | 0.05   |

    We sum these metrics to score X's contribution to the index.
  </Tab>
  <Tab title="Google Trends">
    ### **SerpAPI Google Trends SDK (Paid)**

    - **Frequency:** Data collected hourly, not normalized.
    - **Standardization:** To eliminate volatility inherent in single-keyword Google Trends comparisons, we calibrate results for the keyword against four stable control terms: `ankle sprain`, `wrist pain`, `broken bone`, and `blurry vision`.
    - **Discovery:** We use the `search` endpoint with parameters`engine = google_trends`, `date = now 1-d`, and `q = {keyword}, ankle sprain, wrist pain, broken bone, blurry vision` . We use the averages returned for our calculations.

    <Steps>
      <Step title="Calculate Baseline">
        We take the simple average of the four control terms' averages.
      </Step>
      <Step title="Standardize Keyword">
        We divide the keyword's average interest by (baseline average + 1).
      </Step>
      <Step title="Calculate Final Metric">
        We apply a $log(x+1)$ transformation to the result.
      </Step>
    </Steps>
    <Expandable title="Example: Claude Code">
      If "Claude Code" has an average 24hr interest of `35.0` and the control baseline is `1.0`:

      $$
      \log\left(\frac{35.0}{1.0 + 1}\right) = \log(17.5)
      $$
    </Expandable>
  </Tab>
</Tabs>

## Final Calculation

The **Attention Index** is the final weighted combination of the Social Metrics and Google Trends, scaled by a factor of 10.

| Variable | Platform      | Weight              |
| :------- | :------------ | :------------------ |
| **G**    | Google Trends | 30%                 |
| **Y**    | YouTube       | 28% (40% of Social) |
| **R**    | Reddit        | 21% (30% of Social) |
| **X**    | X (Twitter)   | 21% (30% of Social) |

### Formula

$Index = 10 \cdot [0.30G + 0.70(0.40Y + 0.30R + 0.30X)]$

<Expandable title="example">
  Suppose platform scores (post-transformation) are Y=6.0, R=4.0, X=5.0, G=1.0:

  1. Social Metric: $0.40(6.0) + 0.30(4.0) + 0.30(5.0) = 5.10$
  2. Preliminary Index: $0.30(1.0) + 0.70(5.10) = 3.87$
  3. Final Index: $3.87 \cdot 10 = 38.7$ (Index Points)
</Expandable>
